## 로컬 미리보기

Python이 설치된 환경에서 저장소 루트를 기준으로 실행합니다.

```sh
python -m http.server 8000 --bind 127.0.0.1
```

브라우저에서 `http://127.0.0.1:8000/`을 엽니다.
수묵화 콘셉트는 `/concept/ink-brush/`에서 확인할 수 있습니다.
