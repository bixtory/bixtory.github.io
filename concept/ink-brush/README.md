# 수묵화 콘셉트

먹의 농담과 붓의 필획으로 브랜드 철학을 표현한 독립 디자인 시안입니다.
제목·본문·버튼·아이콘·구분선에 같은 표현을 연결했습니다.

## 보기와 조작

저장소 루트에서 정적 서버를 실행하고 `/concept/ink-brush/`를 엽니다.

- 상단 메뉴와 본문의 링크로 각 영역을 탐색합니다.
- 체험 영역에서 마우스나 터치를 움직이면 먹의 흔적이 쌓입니다.
- 체험 영역에 키보드 초점을 두고 방향키·Enter·Space로 흔적을 남깁니다.
- 움직임 멈추기·이어가기와 장면 비우기로 체험 상태를 조작합니다.
- 모바일 메뉴는 메뉴 버튼으로 열고, 항목 선택이나 Escape로 닫습니다.
- 시스템의 움직임 감소 설정에서는 흔적이 자동으로 이동하지 않습니다.

## 구성과 자산 출처

`index.html`, `style.css`, `main.js`와 `assets/`로 구성됩니다.
이미지와 폰트를 함께 제공하므로 별도의 빌드나 외부 폰트 요청이 필요하지 않습니다.

원본 시안의 이미지·폰트·라이선스 파일을 변경 없이 보존했습니다.
출처와 SHA-256은 [자산 기록](asset-provenance.json)에서 확인할 수 있습니다.
자산 기록의 저장 위치는 이 디렉터리를 기준으로 표기했습니다.

- 수묵 배경: 이 시안을 위해 생성한 이미지.
- East Sea Dokdo: [Google Fonts 원본](https://github.com/google/fonts/tree/e7db6ca603fd4862010383ff17ffd6cc4ffac1c0/ofl/eastseadokdo), [OFL](assets/fonts/eastseadokdo/OFL.txt).
- 연성체: [Google Fonts 원본](https://github.com/google/fonts/tree/e7db6ca603fd4862010383ff17ffd6cc4ffac1c0/ofl/yeonsung), [OFL](assets/fonts/yeonsung/OFL.txt).
- 나눔명조: [Google Fonts 원본](https://github.com/google/fonts/tree/e7db6ca603fd4862010383ff17ffd6cc4ffac1c0/ofl/nanummyeongjo), [OFL](assets/fonts/nanummyeongjo/OFL.txt).

폰트의 저작권 고지와 라이선스는 각 폰트 디렉터리에 함께 보관합니다.
